# Gem Screener logo (concept A, "Viewfinder gem")

The chosen direction: a gem inside scanner corners (the screener found one), the name "Gem Screener", the tagline "Revenue-driven AI Research" and "by CyMetica". Kept here for the next spec.

| File | Use |
|---|---|
| `svg/gem-screener-logo-A-horizontal.svg` | the main logo, for the page header and wide places |
| `svg/gem-screener-logo-A-stacked.svg` | squares, avatars, splash screens |
| `svg/gem-screener-logo-A-one-colour.svg` | print or a single-ink stamp (white; put it on a dark ground) |
| `svg/gem-screener-icon-A.svg` | the icon with the scanner corners, 32 px and up |
| `svg/gem-screener-icon-A-small.svg` | the gem alone, for favicons and anything under 32 px |
| `png/` | the same as PNG: transparent, and `-on-dark` on the page background |

All words are outlined (no font needed). The colours and fonts are the page's own:

- name: Archivo Black, white
- tagline: IBM Plex Sans Bold, green `#00ff88`
- "by": `#6f8199`, "CyMetica": cyan `#00cfff`
- gem and corners: gradient from `#00cfff` to `#00ff88`
- dark ground: `#0a0e17`

Spelling: "Revenue-driven AI Research" (with the hyphen), "by CyMetica" (capital C and M).

The other two directions (B sliced gem, C scope gem) are not kept here.
